## Execution procedure

Use Thor for V888 computation. Confirm the actual execution channel and runner/host
identity before claiming a machine operation. Do not ask the user to run routine
commands. If access is missing, record the blocker; do not claim execution and do
not substitute another host for an unreported hardware result.

Keep raw data external. Verify exact hashes/generation, integer IDs, detector version,
filter policy and the node set before importing an artifact. The 19.73 GB raw table
and the 42,309,621-contact induced graph are different scopes. No deletion or in-place
filtering of the raw table is allowed by this bootstrap.

Inspect current SciRust primitives and the receiving repository's bootstrap before
adding a dependency. New executable dynamics belong in Rust, with CPU reference and
independent tests first. Python remains acceptable for the existing frozen scientific
reference, metadata validation, ingestion and independent oracles; this does not turn
a Python script into the requested Rust simulation engine.

For every slice, retain the hypothesis, exact source/data/protocol, tests, resource
budget, outcome, limitations, PR target and next dependency. Preserve failed hypotheses.
Update the ledger after observations, not after promises. Add a dated checkpoint when
facts change and update this read-order pointer to the latest checkpoint. Do not erase
older observations or copy stale status into a new date.
