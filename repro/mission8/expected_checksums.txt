# Canonical digests of the OFFLINE Mission 8 fixture results, computed by
# itd_research.mission8.campaign.canonical_result_digest (JSON, sorted keys, with the
# declared non-deterministic fields removed: environment, full_p95_ms, profile_p95_ms,
# speedup -- see NONDETERMINISTIC_FIELDS).
#
# ---------------------------------------------------------------------------------------
# THESE DIGESTS ARE ENVIRONMENT-STAMPED AND **NOT PORTABLE** ACROSS MACHINES.
# ---------------------------------------------------------------------------------------
# They certify run-to-run determinism WITHIN one environment. They are NOT a cross-machine
# guarantee and CI does not gate on them, because the underlying BLAS/LAPACK build changes
# the last ~1e-15 of two quantities:
#
#   * h73_structural_ood ... mean_global_mahalanobis  (covariance inversion)  ~8.9e-16
#   * h70_lead_time_established.threshold             (score quantile)        ~1.3e-18
#
# Those round-off differences propagate into the SHA-256 and produce a different digest for
# identical, equally-correct results. This corroborates Mission 7's finding that
# cross-environment agreement is ~1.6e-16 rather than bit-identity.
#
# Observed full-validation digests for the SAME code:
#   Python 3.11.15 / NumPy 2.3.5 / dev container   7220974dd51c5389b6446137e8cef5aab09d2ab85f4c17ea3e7f803a44f5d324

#   Python 3.11.15 / GitHub Actions runner         f75bd4040465e075ebc3834caa8b6fafcfc9bdd9129dc8e3d12f3220b0d4a639
#
# To reproduce meaningfully: run the campaign TWICE in YOUR environment and confirm the two
# digests match each other (step 3 of commands.sh). Comparing against a digest produced on
# a different machine is expected to differ and is not a failure.
#
# What IS portable and IS enforced by tests/test_mission8.py:
#   * every scientific field is bit-identical run to run within one process/environment;
#   * only the declared wall-clock fields differ (asserted in BOTH directions, so the
#     strip-set cannot be widened to mask a genuine determinism defect).
