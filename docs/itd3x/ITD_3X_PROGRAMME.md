# ITD Research Lab — Programme ITD-3X

Status: **bootstrap active**

Research-engine revision: **ITD Research Lab V30.0-alpha**

Frozen scientific baseline: **ITD V29.18**

## Identity

The project is evolving from ITD Simulator into **ITD Research Lab**: a comparative laboratory for structural representations, trajectories, uncertainty, interventions and adaptive systems.

The repository and Python package names remain unchanged during the bootstrap so existing V29.18 users and validation paths remain compatible.

ITD V29.18 is a frozen reference lineage. ITD-3X is a separate research-engine lineage that may consume V29.18 but must never change its numerical semantics to improve a downstream result.

## ITD-3X rules

1. Every new mechanism is research-only until explicitly promoted.
2. Negative, blocked, inconclusive and equivalent outcomes are first-class.
3. Final holdouts cannot be used for selection or search.
4. Ecosystem integrations preserve ownership boundaries.
5. SciRust is preferred for reusable scientific primitives.
6. Forge may search candidates but cannot own confirmatory conclusions.
7. ElasticXxx receives evidence, not automatic runtime policy.
8. FLAT-ATTENTION owns execution semantics and device qualification.
9. TDI owns recovery/adaptive-inference semantics.
10. SciRust-Verify owns evidence normalization/integrity, not ITD scientific interpretation.

## Promotion rule

A V30+ research mechanism can become a new certified scientific model only through a separate scientific-revision review containing an explicit mathematical definition, independent analytical oracles when possible, convergence and invariance tests, independent implementation comparison where practical, falsifiable external validation, uncertainty/failure-domain documentation, and evidence tied to exact source/data/protocol identities.

Until that process completes, the label remains **ITD Research Lab V30.x research engine**, not a certified replacement for ITD V29.18.
