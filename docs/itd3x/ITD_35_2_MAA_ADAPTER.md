# ITD-35.2 — Multi-Algebra Attention evidence adapter

Status: **implementation slice active**

## Upstream ownership

Multi-Algebra Attention is owned by FLAT-ATTENTION. Its research contract separates Boolean admission, F2 affine predicates, Zhegalkin/ANF nonlinear predicates and max-plus readiness constraints while retaining dense qualified FLAT attention as the numerical reference.

ITD-35.2 records that evidence without changing MAA semantics.

## Route identity

`MaaRouteRef` binds:

- exact FLAT source revision;
- split role;
- ordered algebraic-domain set;
- frozen policy SHA-256;
- feature-schema SHA-256;
- dataset SHA-256;
- explicit recomposition policy.

The Boolean admission domain is mandatory because the current nested MAA design is defined over the existing Boolean control plane.

## Numerical observations

`MaaNumericalObservation` retains:

- case and arm identity;
- upstream evidence disposition;
- exact selected candidate IDs in source order;
- score-evaluation count;
- retained dense-reference relevance count;
- output maximum absolute error;
- LSE absolute error;
- explicit empty-selection state.

Empty selection must not fabricate an output, LSE diagnostic or dense fallback.

## Evidence classification

ITD preserves upstream classifications including exploratory/smoke and confirmatory rejection. A FLAT `FRONTIER_REJECT` or other negative result must not be rewritten as positive evidence by ITD.

## Non-claims

MAA host evidence in ITD cannot authorize:

- a claim that MAA replaces softmax;
- a hardware-performance claim;
- production runtime routing.

Max-plus readiness is not interpreted as numerical irrelevance unless an upstream frozen policy explicitly defines that distinct experiment.
